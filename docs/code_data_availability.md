# Code and Data Availability

This repository contains a standalone reproducibility release of the synthetic `v3_health` healthcare benchmark.

All experiments use fully synthetic data generated by the SCM in this repository. No real patient records are included.

## Reproduction

Install:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-lock.txt
pip install -e . --no-deps --no-build-isolation
```

Run:

```bash
v3-health run --config configs/v3_health_default.yaml --output-dir results
v3-health dashboard --results results/results_summary.json --output results/dashboard.html
```

Regenerate checked-in camera-ready tables and figures:

```bash
scripts/rebuild_tables.sh
scripts/rebuild_figures.sh
```
